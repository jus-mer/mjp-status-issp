# ntile function without NAs
ntile_zero_na <- function(x, n = 10) {
  out   <- rep(NA_real_, length(x))
  is_na <- is.na(x)
  is0   <- !is_na & x == 0
  pos   <- !is_na & x > 0
  out[is0] <- 0
  if (any(pos)) out[pos] <- ntile(x[pos], n)
  out
}

# ntile function without NAs
ntile_zero_na <- function(x, n = 10) {
  out   <- rep(NA_real_, length(x))
  is_na <- is.na(x)
  is0   <- !is_na & x == 0
  pos   <- !is_na & x > 0
  out[is0] <- 0
  if (any(pos)) out[pos] <- ntile(x[pos], n)
  out
}

# ntile function without NAs
ntile_zero_na <- function(x, n = 10) {
  out   <- rep(NA_real_, length(x))
  is_na <- is.na(x)
  is0   <- !is_na & x == 0
  pos   <- !is_na & x > 0
  out[is0] <- 0
  if (any(pos)) out[pos] <- ntile(x[pos], n)
  out
}

# ntile function without NAs
ntile_zero_na <- function(x, n = 10) {
  out   <- rep(NA_real_, length(x))
  is_na <- is.na(x)
  is0   <- !is_na & x == 0
  pos   <- !is_na & x > 0
  out[is0] <- 0
  if (any(pos)) out[pos] <- ntile(x[pos], n)
  out
}

10.4 Descriptive ESeC

To select the most appropriate class scheme, we consider two factors: 1) the number of valid cases and 2) the distribution of the classes.

In the case of the EGP classification scheme, we first tested its 5-class version (see Figure 1), where we observed that White-collar workers are the largest category in all countries, followed by Skilled workers. The Petty Bourgeoisie varies in prevalence depending on the country, while Farm Workers and Unskilled workers are nearly nonexistent in most countries. Due to this overrepresentation of certain classes, we decided to test in additional way the 3-class EGP framework (see Figure 2). Here, we see a slightly more balanced distribution between non-manual workers and manual workers, while farm workers continue to represent a minimal percentage of the population.

We then tested the 5-category ESeC framework (see Figure 3). Although the category of salariats is the most prevalent in most countries, the other categories also have levels of frequency that can be useful when considering the analysis phase. Compared to the five-class EGP framework, the ESeC framework is better able to identify the various socioeconomic sectors that exist today.

Therefore, even though the EGP framework has a higher number of valid cases than the ESeC framework (~5%), the latter allows for a better observation of differences in objective status, making it a better alternative for the operationalization of class in international comparisons
